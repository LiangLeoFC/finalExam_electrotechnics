# 电工学刷题

学习通《电工学》章节测验题库的刷题网页，纯前端、零依赖。

## 功能

- **单一题库**：按章节选择测验刷题（21 个测验，165 题）
- **全部乱序**：全题库随机顺序
- **错题练习**：自动收集错题（含学习通原始错题）
- **收藏夹**：收藏重点题目
- **即时判分 / 整组判分** 两种模式
- 填空题采用「显示答案 + 自评」，避开学习通精确匹配的坑
- 答案来源标注：已验证 / AI推断 / 待核对
- 进度、错题本、收藏存浏览器 localStorage

## 键盘快捷键

- `←` `→`：上一题 / 下一题
- `A`-`E` 或 `1`-`5`：选择选项（判断题 `1`=对 `2`=错）
- `空格`：显示填空答案
- `Enter`：确认多选

## 数据说明

- 题库来自学习通《电工学》章节测验（2026-10 抓取）
- 2.6.1、3.5.1 两个测验启用了字体加密，未收录
- 答题进度只存在本地浏览器，清除缓存会丢失
