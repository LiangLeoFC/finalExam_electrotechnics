# 电工学刷题

学习通《电工学》章节测验题库的刷题网页，纯前端、零依赖。

**在线刷题**：<https://liangleofc.github.io/finalExam_electrotechnics/>

## 功能

- **单一题库**：按章节选择测验刷题（21 个测验，165 题）
- **全部乱序**：全题库随机顺序
- **错题练习**：自动收集错题（含学习通原始错题）
- **收藏夹**：收藏重点题目
- **即时判分 / 整组判分** 两种模式
- 填空题采用「显示答案 + 自评」，避开学习通精确匹配的坑
- 答案来源标注：已验证 / AI推断 / 待核对
- 进度、错题本、收藏存浏览器 localStorage

## AI 助教

- 右下角「✨ AI 助教」打开聊天面板，基于全部题库内容答疑
- **划词提问**：刷题时用鼠标划选题干/选项（公式图片也行），点「✨ 问 AI」即可针对选中内容提问
- 模型：智谱 GLM-4.5-Flash（免费），含图片时自动切换 GLM-4V-Flash 视觉模型
- API Key：在面板 ⚙ 设置里粘贴（bigmodel.cn 手机号注册即得免费 Key），Key 只存在你自己的浏览器里
- 防滥用：浏览器端限流 5 次/分钟、100 次/天

## 键盘快捷键

- `←` `→`：上一题 / 下一题
- `A`-`E` 或 `1`-`5`：选择选项（判断题 `1`=对 `2`=错）
- `空格`：显示填空答案
- `Enter`：确认多选

## 数据说明

- 题库来自学习通《电工学》章节测验（2026-10 抓取）
- 2.6.1、3.5.1 两个测验启用了字体加密，未收录
- 答题进度只存在本地浏览器，清除缓存会丢失
